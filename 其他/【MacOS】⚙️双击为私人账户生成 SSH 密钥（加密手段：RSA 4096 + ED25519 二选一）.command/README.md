## 🔥 <span id="前言">前言</span>

生成私人 [**GitHub**](https://github.com) 账户使用的 SSH 密钥与配置。入口：[同名脚本](<./【MacOS】⚙️双击为私人账户生成 SSH 密钥（加密手段：RSA 4096 + ED25519 二选一）.command>)。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、功能覆盖 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

- 选择 ED25519 或 RSA4096。
- 收集邮箱。
- 生成无口令密钥。
- 写 SSH 配置、准备 ssh-agent。
- 打开 [**GitHub**](https://github.com) SSH 设置并测试连接。
